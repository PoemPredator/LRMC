# 刚晃耦合飞行器姿态自抗扰解耦控制

针对刚体运动、结构弹性振动与液体晃动相互耦合引起的姿态控制问题，开展耦合动力学建模、扩张状态观测器（ESO）设计、扰动估计补偿及多通道姿态解耦控制，提升复杂动力学条件下的姿态控制能力。

本项目包含**贮箱液体晃动参数的建模与拟合**、**刚–晃耦合动力学仿真**、**基于自抗扰的姿态控制器**以及**参数拉偏鲁棒性验证**四部分，主体为 MATLAB 脚本实现。

> 代码根据《动力过程姿态控制研究报告》编写，最后更新于 2025.06。

---

## 主要功能

- **晃动参数拟合**：读取 4 个贮箱的推进剂-晃动参数数据，对摆长、阻尼、晃动质量、转动惯量等量做多项式 / 分段 / 抛物线拟合，并提供异常数据"最近邻"处理。
- **耦合动力学仿真**：将液体晃动等效为单摆模型，与刚体姿态运动、弹性振动耦合，按固定步长积分推进。
- **自抗扰控制**：三通道（滚转/偏航/俯仰）独立设计 ESO 与控制律，实时估计并补偿总扰动。
- **拉偏验证**：对推进剂质量、摆长、初始姿态角等参数在给定范围内随机拉偏，批量运行并统计姿态控制性能。
- **结果可视化**：输出姿态角、角速度、控制量、扰动估计对比、拟合曲线等多组图窗，并可自动保存到指定目录。

## 主要配置项

脚本头部集中了一批开关与参数，常用的如下：

| 变量 | 含义 |
| --- | --- |
| `iter_time` | 拉偏组合的重复次数（默认 1:30） |
| `rand_m` / `rand_k` | 选择推进剂初始质量与初始状态的组合索引 |
| `M_TK_ROBUST_KEY` | 是否对晃动质量 `m_T_k` 拉偏 |
| `L_K_ROBUST_KEY` | 是否对晃动摆长 `L_k` 拉偏 |
| `PENDULUM_ROBUST_KEY` / `PENDULUM_ROBUST_KEY2` | 摆长拉偏方式（比例 / 叠加）开关 |
| `M_K_ROBUST_KEY` | 是否对 `m_k` 拉偏 |
| `FITTING` / `INTERPOLATION` | 选用拟合还是查表插值获取晃动参数 |
| `T_CTR` / `T_ctr` | 是否启用周期控制及控制周期（默认 10 个步长） |
| `T_ESO` / `T_eso` | 是否启用周期更新 ESO 及更新周期 |
| `dest_path` | 仿真图片保存目录 |

仿真时长与控制参数：

```matlab
t_end      = 600;            % 仿真总时长 (s)
t_interval = 0.0128;         % 积分步长 (s)
T_ctr      = 10*t_interval;  % 控制周期
T_eso      = 10*t_interval;  % ESO 更新周期
```

控制器增益位于 `omegaa_c`、`w_o` 附近：

```matlab
kk1 = omegaa_c^2;          k1 = diag([k11 k12 k13]);   % 姿态误差反馈
kk2 = 1.5*2*omegaa_c;      k2 = diag([k21 k22 k23]);   % 角速度反馈
w_o  = diag([w_o1 w_o2 w_o3]);                          % 观测器带宽
w_os = w_o/5;                                           % 周期更新时的降带宽取值
```

## 算法要点

**扩张状态观测器（三阶）**

```
eta_new = eta_cur + (-w_o*eta_cur - w_o^2*omega - w_o*B_0*U) * dt
Z_new   = eta_cur + w_o*omega
```

其中 `Z` 为对总扰动（刚柔耦合、液体晃动、外部干扰等）的估计。

**自抗扰控制律**

```
U_adrc = inv(B_0) * (-k1*theta - k2*omegaa - Z)
```

即将"姿态+角速度"的 PD 反馈与扰动估计补偿项 `Z` 叠加后，经控制效率矩阵 `B_0` 反解为等效控制量，实现对三通道的解耦控制。

> 注意：`B_0`、`k1`、`k2` 与 `Z` 需在每一步长保持维度一致；启用周期控制时，非更新步长沿用上一步控制量，可显著降低计算量但需关注控制间隔对稳定性的影响。

## 输出结果

- 图窗：姿态角 `theta` 三轴分量、角速度、控制量 `U_adrc`、ESO 估计扰动与计算扰动的对比、各贮箱晃动参数的拟合曲线及相对误差等。
- 图片：按参数组合命名（含 `m_1`、`omega_0`、`w_o` 等信息）保存到 `dest_path`，便于对比不同控制参数与拉偏条件下的结果。

---

## 拉偏验证流程

1. 打开对应 `*_ROBUST_KEY` 开关，脚本在给定区间内随机生成参数偏差（如 `m_T` ∈ ±100/±200 kg、`L_k` ∈ ±0.3/±0.5 m）。
2. 循环运行 `iter_time` 次，记录每次的姿态响应。
3. 筛选出表现较差的参数组合，固定为常量，再调整控制增益复验其性能。
4. 将验证结果与拉偏前基线对比，评估鲁棒性边界。

## 注意事项

- `model_parameter.m` 与数据表未随仓库提供，缺失时脚本无法运行。
- 脚本中部分注释为历史实验记录（含日期），保留以便追溯参数调整过程。
- 运行时间较长（默认 30 次拉偏循环 × 600 s 仿真），建议先用较小 `iter_time` 与 `t_end` 调试。
- 结果目录需提前创建，否则 `saveas` 会因路径不存在而报错。
